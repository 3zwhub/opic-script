# opic-script

OPIc 스크립트와 연습용 트레이너(opic_trainer).

- `opic_trainer.html` — 브라우저로 여는 트레이너 (빌드 결과물)
- `trainer_src/` — 트레이너 소스. 다시 만들기: `python -I trainer_src/build.py .` (자세한 내용은 `trainer_src/README.txt`)
- `combos.txt`, `일반_260727_1_edited.txt`, `키워드_문장.txt`, `표현_모음.txt` — 스크립트·키워드·표현 자료
- `netlify_site/` — 배포용 (index.html + 미리 만든 음성 mp3 `tts/`)

교재 사진과 교재 원문은 저작권 때문에 저장소에 넣지 않았습니다.
